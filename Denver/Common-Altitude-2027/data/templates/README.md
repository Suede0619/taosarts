# Blank operational schemas

These twelve CSV files contain headers only, with no real person, buyer, contract, order or financial record. Copy them into a controlled private system before use. Never populate public Git with personal or confidential operational data.

- artwork-intake.csv
- engagement-register.csv
- sponsor-benefits.csv
- rights-register.csv
- purchase-and-changes.csv
- incident-register.csv
- seller-order-reconciliation.csv
- decision-register.csv
- staff-shifts.csv
- visitor-support.csv
- room-and-capacity.csv
- role-brief.csv

Use stable IDs and actual evidence. Leave unknown figures blank or mark them unknown. The central private operations register remains the authority for named accepted roles/commitments. These files define record formats. Keep live records in private operations. Professional/legal/financial records require the actual accepted process and advice. Refer to [drafting aids](../../operations/04-Commercial-and-Rights-Templates.md).
